# NSE NNF Protocol Analysis: Broadcast Message Codes, Error Codes, and Headers

## Overview
This document provides a comprehensive analysis of the NSE (National Stock Exchange) Non-NEAT Front End (NNF) protocol document, focusing on broadcast-related message codes, error codes, and broadcast header structures.

## Broadcast Header Structure (BCAST_HEADER)

The broadcast header is 40 bytes and prefixes all broadcast messages:

```
Structure Name: BCAST_HEADER
Packet Length: 40 bytes

Field               Data Type    Size    Offset
Reserved            CHAR         2       0
Reserved            CHAR         2       2
LogTime             LONG         4       4
AlphaChar           CHAR         2       8
TransactionCode     SHORT        2       10
ErrorCode           SHORT        2       12
BCSeqNo             LONG         4       14
Reserved            CHAR         1       18
Reserved            CHAR         3       19
TimeStamp2          CHAR         8       22
Filler              BYTE         8       30
MessageLength       SHORT        2       38
```

### Header Field Descriptions:
- **LogTime**: Time when message was generated by trading system host
- **AlphaChar**: First two characters of Symbol if structure contains Symbol and Series
- **TransactionCode**: Transaction message number describing the type of message
- **ErrorCode**: Error number describing the type of error (refer to error codes list)
- **BCSeqNo**: Broadcast Sequence number for Ericsson switch (used for FO Market By Price packets)
- **MessageLength**: Length of the entire message

## Common Error Codes

### System Level Error Codes
- **16000**: MARKET_CLOSED - Trading system not available for trading
- **16001**: e$invalid_user - Header user ID not equal to user ID
- **16003**: ERROR_BAD_TRANS_CODE - Invalid Transcode
- **16004**: E$user_already_signed_on - User already signed on
- **16005**: System error while trying to sign-off
- **16006**: E$invalid_signon - Invalid Box/User sign-on
- **16007**: e$signon_not_possible - Signing onto trading system not possible

### Order Related Error Codes
- **16012**: ERR_INVALID_SYMBOL - Invalid Symbol
- **16013**: ERR_INVALID_ORDER_NUMBER - Invalid order number
- **16014**: e$not_your_order - This order is not yours
- **16015**: E$not_your_fill - This trade is not yours
- **16016**: E$invalid_fill_number - Invalid trade number
- **16019**: E$stock_not_found - Stock not found
- **16020**: Order price is outside the revised price range
- **16035**: SECURITY_NOT_AVAILABLE - Security unavailable for trading

### User/Broker Related Error Codes

- **16042**: USER_NOT_FOUND - Dealer does not exist in system
- **16043**: DUPLICATE_RECORD - Record already exists
- **16044**: e$order_modified - Order has been modified
- **16049**: STOCK_SUSPENDED - Stock is suspended
- **16052**: ERR_FUNCTION_NOT_AVAILABLE - Function Not Available

### Trading Error Codes

## Compression and Broadcasting

### LZO Compression
The NSE uses LZO (Lempel Ziv Oberhaumer) compression algorithm for specific broadcast transaction codes:
- 7200 (Market By Order/MBP)
- 7201 (Market Watch)
- 7202 (Ticker)
- 7208 (Only MBP)
- 7220 (Limit Price Protection Ranges)
- 17201 (Enhanced Market Watch)
- 17202 (Enhanced Ticker)

### Sequential Packing
Sequential packing is implemented along with LZO compression to improve effective data transfer and reduce broadcast traffic during market open and close periods.

## Notes
1. All broadcast messages are prefaced with BCAST_HEADER
2. Time fields are number of seconds from midnight January 1, 1980
3. Some transaction codes contain timestamp in nanoseconds from 01-Jan-1980 00:00:00
4. Broadcast Circuit ID (BCID) is used for circuit identification
5. Error codes are referenced in the MESSAGE_HEADER ErrorCode field
6. The suffix "IN" indicates requests from NNF to trading system, "OUT" indicates messages from trading system to NNF
